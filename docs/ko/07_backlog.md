# Backlog

> 아직 하기로 정하지 않은 기능이다. 하기로 정하면 해당 문서로 옮기고 여기서 지운다.

## 발송

- **재전송 식별자**: Sender가 같은 요청을 다시 보내도 한 번만 보내지게 하는 `idempotencyKey`.
- **Sender 발송 한도**: Sender별 분당 발송 수 제한.
- **Sender의 사용자·전체 발송**: 지금은 Operator만 가능하다.

## 채널과 수신 설정

- **비공개 채널**: 초대한 Member만 보고 구독할 수 있는 채널.
- **방해 금지 요일**: 요일별로 다른 방해 금지 시간.
- **긴급 알림의 방해 금지 모드 무시**: Android 방해 금지 접근 권한을 받아 기기 방해 금지 모드에서도 `critical`이 울리게 하기.

## 알림 표시

- **알림 묶음**: 같은 서버의 반복 경고를 하나로 묶기.
- **링크 열기**: 알림을 누르면 지정한 URL 열기.

## 운영

- **앱 안 관리 화면**: 허용, 채널, Sender 관리를 앱에서 하기.
- **기기 간 기록 동기화**: 다른 기기에서 받은 알림 기록 보기.
- **계정 고정**: 첫 로그인한 Google 계정(Firebase UID)에 Member를 묶어, 이메일 주인이 바뀌는 경우에 대비하기.
