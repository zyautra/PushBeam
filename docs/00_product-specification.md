## 1. 제품 개요

### 1.1 제품명

**PushBeam**

서버는 **PushBeam Server**, Android 앱은 **PushBeam for Android**, 관리 도구는 **PushBeam Admin**이다.

### 1.2 한 줄 정의

> **PushBeam은 운영자가 허용한 사람들에게 서버 알림을 보내고, 각자 원하는 알림만 받게 해 주는 개인용 푸시 알림 서비스다.**

### 1.3 목적

- 스크립트, cron, 모니터링 도구가 HTTP 요청 한 번으로 알림을 보낸다.
- 운영자가 허용한 사람만 앱을 받고 알림을 받는다.
- 받는 사람은 어떤 알림을 받을지 스스로 고른다.
- 운영자가 필수로 정한 긴급 알림은 반드시 도착한다.
- 누구에게 무엇이 갔는지 서버에 기록이 남는다.

---

## 2. 해결하려는 문제

FCM 토큰 하나를 서버에 적어 두고 보내는 방식은 혼자 쓸 때는 충분하다.

여러 사람과 함께 쓰면 다음 문제가 생긴다.

- 사람과 기기가 늘 때마다 토큰을 직접 관리해야 한다.
- FCM Topic은 누가 구독하는지 막을 수 없다.
- 인증 없는 발송 API는 누구나 호출할 수 있다.
- 앱 배포 대상과 알림 수신 대상을 따로 관리해야 한다.
- 모두가 모든 알림을 받으니 결국 알림을 꺼 버린다.

PushBeam은 **허용 목록 하나로 앱 배포와 알림 수신을 함께 관리하고, 누구에게 보낼지는 서버가 정한다.**

---

## 3. 원칙

### 3.1 허용한 사람만

운영자가 허용 목록에 넣은 사람만 앱을 받고, 로그인하고, 알림을 받는다. 공개 가입은 없다.

### 3.2 서버가 받는 사람을 정한다

어느 기기로 보낼지는 서버만 정한다. FCM Topic처럼 기기가 스스로 구독하는 방식은 쓰지 않는다.

### 3.3 받는 사람이 고른다

받는 사람은 채널을 구독하거나 해제하고, 음소거하고, 울릴 최소 중요도를 정한다. 구독하지 않은 채널의 알림은 서버가 보내지 않는다. 음소거했거나 최소 중요도보다 낮은 알림은 울리지 않고 앱 목록에만 남는다.

### 3.4 긴급 알림은 반드시 간다

필수 채널의 `critical` 알림은 음소거, 최소 중요도, 방해 금지 시간과 관계없이 소리와 함께 보낸다.

### 3.5 기록이 남는다

FCM 전달은 보장되지 않는다. 대신 서버는 누구에게 보냈고, 누구에게 왜 안 보냈는지 기록한다.

## 4. 구성

| 구성요소              | 역할                                                     |
| --------------------- | -------------------------------------------------------- |
| PushBeam Server       | 허용 목록, 기기, 채널, 구독 관리. 알림 받기, 받는 사람 결정, FCM 전송, 기록 |
| PushBeam for Android  | Google 로그인, 기기 등록, 알림 표시, 받은 알림 목록, 수신 설정 |
| PushBeam Admin        | 운영자용 명령줄 도구. 사용자 허용, 채널·Sender 관리, 기록 조회 |

외부 서비스:

| 서비스                    | 용도                           |
| ------------------------- | ------------------------------ |
| Firebase Cloud Messaging  | 기기로 알림 전달               |
| Firebase Authentication   | Google 계정 로그인             |
| Firebase App Distribution | 허용한 사람에게 앱 배포        |

웹 관리 화면은 없다.

## 5. 역할

| 역할     | 누구                         | 하는 일                                         |
| -------- | ---------------------------- | ----------------------------------------------- |
| Operator | 운영자                       | 사용자 허용·취소, 채널 관리, Sender 발급, 기록 조회, 직접 발송 |
| Member   | 운영자가 허용한 사람         | 앱 설치, 로그인, 알림 수신, 수신 설정            |
| Sender   | 스크립트, cron, 다른 서비스  | 허용된 채널로 알림 발송                          |

운영자도 알림을 받으려면 자신을 Member로 허용하고 앱에 로그인한다.

## 6. 주요 시나리오

### 6.1 초대부터 첫 알림까지

운영자가 지인의 Google 이메일을 허용한다. 지인은 App Distribution 초대 메일을 받아 앱을 설치하고 로그인한다. 로그인하면 기기가 등록되고 필수 채널과 자동 구독 채널에 구독된다. 이후 그 채널의 알림을 받는다.

### 6.2 스크립트에서 발송

운영자가 NAS 모니터링 스크립트용 Sender를 만들고 `server-alerts` 채널에만 보낼 수 있게 한다. 스크립트는 디스크가 차면 `server-alerts`로 `high` 알림을 보낸다. 스크립트는 누가 받는지 모른다.

### 6.3 원하는 알림만 받기

Member는 앱에서 채널 목록을 보고 `deploy`는 구독하고 `general`은 해제한다. `deploy`는 `high` 이상만 받도록 정한다. 필수 채널 `server-alerts`는 해제할 수 없지만 잠시 음소거할 수 있다.

### 6.4 밤에는 조용히

Member가 방해 금지 시간을 23:00~07:00으로 정한다. 이 시간에 온 알림은 소리 없이 목록에만 남는다. 필수 채널의 `critical`은 소리가 난다.

### 6.5 허용 취소

운영자가 한 사람의 허용을 취소한다. 그 사람의 기기는 즉시 발송 대상에서 빠지고, 새 앱 버전도 받지 않는다.

## 7. 기능

### 7.1 사용자 허용

사용자는 Google 계정 이메일로 허용한다.

| 상태      | 의미                          |
| --------- | ----------------------------- |
| `INVITED` | 허용됨, 아직 로그인 안 함      |
| `ACTIVE`  | 로그인함, 알림 받음            |
| `REVOKED` | 허용 취소됨                    |

취소한 사람을 다시 허용하면 `INVITED`로 돌아가고 처음부터 다시 시작한다.

### 7.2 앱 배포

허용 목록과 App Distribution 테스터 그룹은 항상 같게 맞춰진다. 허용하면 그룹에 추가되고, 취소하면 빠진다. 새 앱 버전은 그룹에 배포한다.

### 7.3 채널과 구독

채널은 알림 주제다. 예: `server-alerts`, `deploy`, `backup`

채널은 운영자만 만들며 다음 속성을 가진다.

| 속성      | 의미                                                    |
| --------- | ------------------------------------------------------- |
| 필수      | 모든 Member가 구독하며 해제할 수 없다                    |
| 자동 구독 | 새 Member가 처음에 구독된다. 이후 해제할 수 있다         |

Member는 채널마다 다음을 정한다.

- **구독 / 해제**: 필수 채널은 해제할 수 없다.
- **음소거**: 정한 시각까지, 또는 직접 끌 때까지 울리지 않는다. 앱 목록에는 남는다.
- **최소 중요도**: 이보다 낮은 중요도의 알림은 울리지 않는다. 앱 목록에는 남는다.

### 7.4 알림

알림은 제목, 본문, 중요도, 대상, 그리고 선택 사항인 추가 데이터로 이루어진다.

| 중요도     | 의미                         | 표시                      |
| ---------- | ---------------------------- | ------------------------- |
| `critical` | 즉시 조치 필요               | 소리·진동                 |
| `high`     | 빨리 확인해야 함             | 소리·진동                 |
| `normal`   | 일반 알림                    | 소리                      |
| `low`      | 기록용                       | 무음                      |

| 대상     | 받는 사람                  | 보낼 수 있는 사람         |
| -------- | -------------------------- | ------------------------- |
| 채널     | 그 채널 구독자             | Operator, 허용된 Sender   |
| 사용자   | 지정한 Member              | Operator                  |
| 전체     | 모든 `ACTIVE` Member       | Operator                  |

### 7.5 수신 규칙

채널 알림을 Member 한 명에게 보낼지는 다음 순서로 정한다.

1. 채널을 구독하지 않았으면 보내지 않는다.
2. 필수 채널의 `critical`이면 소리와 함께 보낸다. 아래 규칙을 보지 않는다.
3. 음소거 중이면 알림 없이 앱 목록에만 보낸다.
4. 최소 중요도보다 낮으면 알림 없이 앱 목록에만 보낸다.
5. 방해 금지 시간이고 `critical`이 아니면 무음으로 보낸다.
6. 그 외에는 보낸다.

사용자·전체 대상 알림은 구독과 관계없이 보내며 5번만 적용한다.

### 7.6 방해 금지 시간

Member는 매일 적용되는 시작 시각과 종료 시각을 정한다. 자정을 넘을 수 있다(예: 23:00~07:00). Member의 시간대 기준이며, 모든 기기에 같이 적용된다.

### 7.7 기록

서버는 다음을 90일 동안 기록한다.

- 보낸 알림: 보낸 주체, 대상, 내용, 시각
- Member별 결과: 보냄, 무음으로 보냄, 음소거로 목록만, 최소 중요도로 목록만 등
- 기기별 전송 결과: 대기, 성공, 실패, 토큰 무효, 취소

앱은 받은 알림을 기기에 보관하고 읽음 표시와 걸러 보기를 제공한다.

## 8. 보안

- 서버는 HTTPS로 인터넷에 공개한다. VPN은 쓰지 않는다.
- 모든 API는 인증한다. 헬스 체크만 예외다.

| 역할     | 인증                                       |
| -------- | ------------------------------------------ |
| Operator | Operator Token                             |
| Member   | Google 로그인(Firebase ID Token) + 허용 목록 확인 |
| Sender   | Sender Key                                 |

- Sender Key는 발급할 때 한 번만 보여 주고 서버에는 hash만 저장한다.
- Firebase 서비스 계정 키, 앱 서명 키, Sender Key, Operator Token은 저장소와 로그에 남기지 않는다.
- 알림 내용은 FCM(Google)을 거친다. 비밀번호 같은 비밀 값을 알림에 담지 않는다.

## 11. 꼭 지킬 규칙

1. 허용 목록에서 `ACTIVE`가 아닌 사람에게는 알림이 가지 않는다.
2. 받는 사람은 서버만 정한다. FCM Topic을 쓰지 않는다.
3. 인증된 Operator와 Sender만 보낼 수 있고, Sender는 허용된 채널로만 보낸다.
4. Member가 구독하지 않은 채널 알림은 보내지 않고, 음소거·최소 중요도 미만 알림은 울리지 않는다. 필수 채널의 `critical`만 예외다.
5. 서버가 받은 알림은 서버가 재시작되어도 기록과 함께 남고 전송이 이어진다.
6. 비밀 값은 저장소, 로그, 알림 내용에 들어가지 않는다.
